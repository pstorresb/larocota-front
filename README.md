# La Rocota — frontend

Tienda pública, cuenta de cliente y portal administrativo construidos con Next.js App Router y TypeScript.

## Desarrollo

1. Copia `.env.example` a `.env.local`.
2. Ejecuta `npm install`.
3. Inicia con `npm run dev`.

La variable `NEXT_PUBLIC_API_URL` debe apuntar a la API Fastify. Antes de publicar, ejecuta `npm run lint` y `npm run build`.
